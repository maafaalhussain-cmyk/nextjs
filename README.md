# J & M — سوق إلكتروني

تطبيق سوق إلكتروني مبني باستخدام Next.js وReact وTypeScript وSupabase، مع واجهة عربية باتجاه RTL.

## أهم المسارات
- `/` واجهة المتجر.
- `/login` تسجيل الدخول الحالي.
- `/register` إنشاء حساب.
- `/account` حساب العميل.
- `/seller` بوابة البائع.
- `/owner` لوحة المالك (تتطلب دور owner في `public.user_roles`).
- `/owner/products` إدارة المنتجات.
- `/owner/orders` عرض الطلبات.
- `/owner/finance` تقرير دفتر الأستاذ.
- `/owner/supervisors` معلومات إعداد إدارة الفريق.

## الإعداد
1. اضبط `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` في بيئة النشر.
2. راجع ملفات SQL في `supabase/migrations` وقارنها مع حالة قاعدة البيانات الموجودة قبل تنفيذ أي ترحيل.
3. بعد التأكد من وجود مخطط السوق الأساسي، اتبع `docs/OWNER_SETUP.md` لتعيين حساب المالك.
4. اختبر تسجيل الدخول، رفض الوصول لغير المالك، إنشاء منتج، وقراءة التقارير على بيئة اختبار قبل التشغيل التجاري.

## أوامر محلية
- `npm install`
- `npm run dev`
- `npm run build`

## تنبيهات مهمة
- لا تضع مفاتيح Supabase السرية أو مفاتيح الدفع في ملفات الواجهة أو المستودع.
- صفحة المنتجات تحتاج تطبيق ترحيل صلاحيات المالك.
- تقرير المال يعتمد على `get_financial_report` والقيود المالية المرحّلة فقط.
- الدفع والاسترداد وإدارة الحسابات الإدارية يجب أن تتم عبر خادم موثوق مع تحقق صلاحيات.
- ملفات الترحيل الموجودة تتضمن نسخاً قديمة ومتعددة من بعض الأرقام؛ لا تعِد تشغيل جميع ملفات SQL على قاعدة إنتاج قبل مراجعة سجل الترحيلات ومخطط Supabase الفعلي.
